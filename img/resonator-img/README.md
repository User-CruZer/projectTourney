# Resonator portraits

One picture per resonator, using the **exact file name** below. The 61 current ones are 256×256 head icons downloaded from encore.moe.
Any of `.webp`, `.png` or `.jpg` works (checked in that order). Square pictures (for example 256×256) look best.
The pages find them automatically; a resonator without a picture keeps its coloured initials.

To add a new resonator: add it to `ROSTER` in `js/config.js`, put its picture here, then bump the `?v=` tag and refresh the control page and the OBS sources.
